## 4. 핵심 해석

### 4.1 EPD는 기존 지표의 재조합이 아니다

**모든 기존 지표와 `|corr| < 0.64`**. 특히:

- **RSI와 음의 상관 (-0.11)** → 모멘텀과 **다른 방향**을 봄
- **AC20과 완전 무관 (0.00)** → 자기상관과 **완전히 다른 것**
- **PE60과 음의 상관 (-0.21)** → 순열 엔트로피와도 다름
- **ATR/MACD/RV20과 < 0.15** → 변동성/추세와 무관

### 4.2 유일한 부분 중복 — `|ret|` (0.55)

**이건 정의상 자연스러움**:
- EPD의 `Z_r`이 "수익률의 z-score" → 수익률 크기와 부분 상관
- **0.7 미만이므로 "중복"이 아닌 "부분 겹침"**
- EPD는 `Z_r` (수익률) + `Z_e` (엔트로피)의 조합 → `|ret|`과 다름

### 4.3 AC20 = 0.00의 의미

**자기상관(autocorrelation)과 완전히 무관**. EPD는 자기상관을 **전혀 반영하지 않음**. 즉:
- EPD는 "가격의 규칙성"을 재지만, **자기상관과는 다른 종류의 규칙성** (순열 패턴).
- 이건 **PE60과도 음의 상관**으로 확인됨.

### 4.4 EPD의 정체성 (Stage 3 확정)

> **EPD는 기존 기술적 지표(RSI, ATR, MACD, RV)와 독립적이며, 수익률 크기(|ret|)와 부분 상관이 있으나 순열 엔트로피(PE60)와도 다른 새로운 축을 제공한다.**
